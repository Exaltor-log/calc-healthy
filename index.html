      Bagikan hari ini

      Teman

      Bagian teman dan thread belum aktif. Untuk sementara kamu bisa membagikan kartu di atas lewat WhatsApp atau aplikasi lain. Nanti tempat ini berisi linimasa makan dan olahraga dari teman yang kamu tambahkan, tanpa mengubah susunan menu ini.

      Kalau olahraga kamu catat di bagian atas, pilih tingkat yang lebih rendah di sini. Kalau tidak, olahraganya terhitung dua kali.

      Fitur foto dan pencarian kalori memakai Gemini dari Google. Ambil API key gratis di aistudio.google.com/apikey, login pakai akun Google, tekan Create API key, lalu salin ke bawah.

      Catatan makanan, olahraga, berat badan, data diri, dan API key disimpan di penyimpanan browser hp ini saja. Tidak ada akun, tidak ada server milik aplikasi ini, dan tidak ada yang bisa melihat catatanmu selain kamu.

      Pengecualian ada satu. Saat kamu memakai fitur foto atau pencarian kalori, foto dan teks yang kamu kirim diteruskan ke server Google untuk dibaca. Di paket gratis, Google menyatakan boleh memakai isinya untuk pengembangan produk mereka. Kalau kamu keberatan, jangan pakai fitur foto, catat manual saja.

      Menghapus data penjelajahan Chrome atau data aplikasi ini di pengaturan Android akan menghapus semua catatanmu, dan tidak ada salinan cadangan di tempat lain.

      Cara memakai. Isi dulu Profil dan target supaya angkanya masuk akal. Lalu tekan tombol kamera di tengah, foto makananmu, periksa hasil bacaannya, dan atur pengali porsi kalau isi piringmu berbeda dari tebakannya.

      Kalau hasil fotonya meleset. Ketik keterangan di kotak di bawah tombol foto, misalnya nasinya tiga centong. Keterangan itu lebih dipercaya daripada tebakan modelnya.

      Pesan kesalahan yang mungkin muncul. Kode 503 berarti server Google sedang penuh, aplikasi akan mencoba ulang sendiri. Kalau kuota satu model habis, aplikasi otomatis pindah ke model berikutnya di daftar dan memberi tahu kamu, karena jatah dihitung terpisah per model. Kuota Google direset tiap jam 2 siang WIB. Kode 400 atau 403 berarti API key salah atau belum aktif. Kode 404 berarti nama model berubah, pilih ulang di Pengaturan AI.

      Olahraga terhitung dua kali. Kalau kamu mencatat olahraga di tab Hari ini, pilih tingkat aktivitas harian yang lebih rendah di Profil, karena tingkat aktivitas itu sudah memasukkan olahraga.

      SnapEat, pencatat kalori dan defisit harian. Aplikasi web yang jalan langsung di browser, tanpa akun dan tanpa server.

      Kebutuhan kalori dihitung dengan rumus Mifflin St Jeor, dan kalori olahraga memakai nilai MET standar yang disesuaikan dengan beratmu. Semua angka di sini perkiraan, bukan hasil timbang atau uji lab. Taksiran dari foto paling sering meleset di bagian porsi dan minyak, jadi pakai pengali porsi kalau isi piringmu berbeda dari yang tertulis. Aplikasi ini membatasi defisit maksimal 500 kkal per hari dan tidak menurunkan target di bawah batas aman. Untuk kondisi kesehatan tertentu atau target yang lebih agresif, bicarakan dulu dengan dokter atau ahli gizi.

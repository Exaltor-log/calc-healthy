    Ambil API key gratis di aistudio.google.com/apikey, login pakai akun Google, tekan Create API key, lalu salin ke bawah. Key disimpan di hp kamu saja. Foto dan nama makanan dikirim ke server Google, dan di paket gratis Google boleh memakai isinya untuk pengembangan produk mereka.

    Bersihkan data

    Kebutuhan kalori dihitung dengan rumus Mifflin St Jeor, dan semua angka kalori di sini adalah perkiraan, bukan hasil timbang atau uji lab. Taksiran dari foto paling sering meleset di bagian porsi dan minyak, jadi pakai pengali porsi kalau isi piringmu lebih banyak atau lebih sedikit dari yang tertulis. Aplikasi ini membatasi defisit maksimal 500 kkal per hari dan tidak menurunkan target di bawah batas aman. Untuk kondisi kesehatan tertentu atau target yang lebih agresif, bicarakan dulu dengan dokter atau ahli gizi.
